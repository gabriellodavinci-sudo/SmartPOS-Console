# SmartPOS — Console Point of Sale System

A full-featured terminal-based Point of Sale system built in C# with a custom arrow-key navigation interface, role-based access control, and persistent file storage.

## Features

- Arrow key navigation menu — no mouse required
- Role-based access — Owner and Employee roles with different permissions
- Real-time product search — filters as you type
- Inventory management — add, edit, delete products with stock tracking
- Color-coded stock warnings — low stock and out of stock indicators
- Sales processing — cart management, quantity selection, payment and change calculation
- Receipt printing — console output and file-saved receipts
- Sales reports — weekly, monthly, and yearly breakdowns
- Employee management — register employees, track individual sales
- File persistence — all data saved between sessions

## Technologies Used

- Language: C#
- Type: Console Application
- Storage: Text file persistence
- IDE: Visual Studio

## How To Run

1. Clone the repository
2. Open the `.sln` file in Visual Studio
3. Build and run the project
4. Login with your employee credentials
5. Navigate using arrow keys and Enter
